## Definitions
- Arrhenius: acid produces $H^+$ in water, base produces $OH^-$
- Bronsted-Lowry: acid = proton donor, base = proton acceptor (more general)
- conjugate pairs: HCl / Cl-, NH3 / NH4+
- strong acids fully dissociate: HCl, HBr, HI, HNO3, H2SO4, HClO4 (memorize the 6)
- weak acids partially dissociate: acetic acid, HF

## pH Scale
$pH = -\log[H^+]$ and $pOH = -\log[OH^-]$, pH + pOH = 14 at 25 C. pH 7 neutral, below 7 acidic, above 7 basic. Each pH unit = 10x change in $[H^+]$. $K_w = [H^+][OH^-] = 1.0 \times 10^{-14}$

## Titration
- neutralization: acid + base -> salt + water
- equivalence point = moles acid = moles base
- use $M_1 V_1 = M_2 V_2$ for monoprotic
- indicator changes color at endpoint, phenolphthalein clear -> pink
- buffer = weak acid + its conjugate base, resists pH change, Henderson Hasselbalch $pH = pK_a + \log\frac{[A^-]}{[HA]}$
