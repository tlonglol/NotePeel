## Ohms Law
$V = IR$. Voltage in volts, current in amps, resistance in ohms. Current = flow of charge $I = \frac{Q}{t}$. Resistance of a wire $R = \rho\frac{L}{A}$, longer = more R, thicker = less R.

## Power
$P = IV = I^2 R = \frac{V^2}{R}$. Units watts. Energy = power x time, kWh on your electric bill.

## Series Circuits
- one path, same current through everything
- $R_{total} = R_1 + R_2 + ...$
- voltages add up to battery voltage
- one bulb burns out -> all go out (xmas lights)

## Parallel Circuits
- multiple paths, same VOLTAGE across each branch
- $\frac{1}{R_{total}} = \frac{1}{R_1} + \frac{1}{R_2} + ...$, total R is less than smallest branch
- currents add: $I_{total} = I_1 + I_2$
- houses wired in parallel so each outlet gets 120 V

## Kirchhoffs Rules
junction rule: current in = current out (charge conservation). loop rule: sum of voltage changes around any closed loop = 0 (energy conservation)
